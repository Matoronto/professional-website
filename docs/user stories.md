# User Stories (Version 1.0)

## Primary audiences

- Recruiters
- Networking contacts
- Potential clients
- Fellow developers

## MVP user stories (for the meetup)

1. **Recruiter — Quick evaluation**
    - As a recruiter, I want to quickly understand the developer’s experience and skills, so that I can evaluate them for potential opportunities.
    - Acceptance criteria:
        - Home page states role focus (Java / Spring) and value proposition
        - About/Experience section summarizes background in 30–60 seconds of reading
        - Clear links to projects + GitHub
        - Resume is accessible in 1 click
2. **Networking contact — Follow-up**
    - As a networking contact, I want to find the developer’s contact information quickly, so that I can continue the conversation after meeting them.
    - Acceptance criteria:
        - Contact info visible from the Home page (button/CTA)
        - Contact page shows email + LinkedIn/GitHub
        - Optional contact form confirms message submission
3. **Potential client — Assess fit**
    - As a potential client, I want to view the developer’s technical work, so that I can determine whether they are a good fit for a project.
    - Acceptance criteria:
        - Projects section includes 2–4 featured projects with outcomes + tech stack
        - Each project has a short problem → solution → results narrative
        - Clear “how to contact” CTA
4. **Fellow developer — Learn and connect**
    - As a fellow developer, I want to review projects and technical experiences, so that I can learn about the developer’s skills and interests.
    - Acceptance criteria:
        - Each project links to README and/or write-up
        - Tech stack is listed per project
        - Optional “learning notes / decisions” link for deeper dives

## Secondary user stories (post-meetup)

- As a visitor, I want the site to look good on mobile, so that I can read it on my phone.
- As a visitor, I want pages to load quickly, so that I don’t abandon the site.
- As Mat, I want to add new projects easily, so that the site stays up-to-date with minimal friction.
